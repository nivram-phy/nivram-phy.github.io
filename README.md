# Niveditha Ram — personal website

A deliberately minimal static academic website for GitHub Pages.

## Files
- `index.html` — homepage + recent news
- `research.html` — research projects with status and keywords
- `teaching.html` — teaching and mentoring
- `talks.html` — selected talks and seminars
- `stardust.html` — The Stardust Collective
- `style.css` — shared styling
- `assets/Niveditha_Ramasubramanian_CV.pdf` — short CV
- `CNAME` — custom-domain configuration

## Add a portrait
Put a file called `profile.jpg` in `assets/`. The homepage already contains the image element; if the file is absent, the portrait area disappears automatically.

## Add a news item
In `index.html`, copy one `.news-row` block and place it at the top of the `news` div.

## Publish with GitHub Pages
Upload these files to the root of a GitHub repository, then enable GitHub Pages from the repository Settings → Pages. The site is plain HTML/CSS and has no build step.
